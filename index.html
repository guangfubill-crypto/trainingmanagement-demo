01

先明确，什么才算做完

输入是一页培训管理系统需求，以及逐步采用 OpenSpec 开发的要求。

业务目标

集中管理课程、学员与登录用户。管理员维护数据，普通用户只能查看课程和学员。

首版边界

完成登录、CRUD、搜索分页、详情和权限控制。报名、考勤、考试、收费不在本轮范围内。

输入 Input处理 Process输出 Output
账号与密码验证凭据，建立会话，按角色授权进入允许访问的功能
课程、学员、用户资料校验字段、编号唯一性与权限可搜索、查看和维护的记录
打包与使用需求冻结后端，封装窗口，保留 WebWindows 安装包与云端配置

来源：用户需求图片、后续桌面版与仓库迁移指令。

一个规格如何落到验收
需求：普通用户只能查看课程与学员。
规则：页面隐藏写入口；服务端对写操作返回 403。
场景：普通用户直接请求课程写 API，仍被拒绝。
证据：后端权限测试 + 浏览器普通用户场景。
交付：规则进入主规格，变更和任务清单归档。
参照 Spec Workspace 的阶段组织方式整理已有事实。本项目采用 OpenSpec；没有把参考页的 Superpowers 工作流、标准包或审批记录追溯宣称为已执行。
03

开发过程，一步一步走通

按实施顺序回顾，每个阶段都留下具体输出。

01 / 建立项目与连通前后端

建立 Vue + FastAPI 骨架和数据库健康检查，验证开发代理、桌面与手机布局。TypeScript 与 vue-tsc 不兼容后，固定 TypeScript 5.9.3 并重新构建。

02 / 完成认证与权限基础

实现管理员初始化、Argon2 密码哈希、HttpOnly Cookie 与服务端会话；角色变化即时生效，修改密码或删除账号撤销会话。

03 / 完成三个业务模块

实现课程、学员、用户增删改查，以及搜索分页、详情、表单校验、删除确认和错误提示。保护最后一个管理员，禁止删除当前登录账号。

04 / 回归与问题修复

执行后端和浏览器测试。手机固定操作列遮挡内容后，改为表格横向滚动并增加提示，再验证分页与窄屏场景。

05 / 增加离线桌面版

Electron 提供独立窗口，PyInstaller 打包后端。首次启动创建管理员；服务只监听回环地址，用每次启动的随机密钥保护访问。

06 / 打包、安装与卸载

生成 NSIS 安装包与免安装 zip。验证单实例、窗口关闭后服务退出、重启数据保留，以及实际安装和卸载后的测试数据库完整性。

07 / 保留云端路径并迁移仓库

保留 Web 开发入口，增加同源静态托管与 Docker Compose。接受协作者邀请，推送完整 Git 历史，切换本地 origin 并核对提交一致。

04

同一套业务，两种运行方式

Vite / Vue 3 / TypeScript / Element Plus / Axios / Pinia / Vue Router。

Windows 本地桌面

Electron → 本机 FastAPI → SQLite。浏览器和后端环境随包交付，用户无需安装开发工具。

Web / 云端

浏览器 → HTTPS 反向代理 → FastAPI → 持久化 SQLite。Docker 配置已提供，公网服务尚未部署。

能力管理员普通用户
课程与学员新增、查看、编辑、删除搜索、分页、详情
用户管理账号、角色、重置密码无访问权限
权限执行页面与 API 双层控制，直接请求也不能绕过
桌面与云端数据库相互独立，暂不自动同步。桌面数据在用户目录保存，关闭应用后备份整个 data 文件夹。

07

下一轮，从现有规格继续

保留已有成果，把新增需求作为独立变更。

  1. 读取主规格和验收记录，确认本轮业务目标。
  2. 新建 OpenSpec 变更，定义范围、设计、任务和验收。
  3. 逐项实现，保存可复查的测试与审查证据。
  4. 验证后同步主规格、归档并发布对应版本。

可以继续的方向

云端实际部署、桌面签名与更新、真实数据迁移演练。报名、考勤或收费等新业务需要另行定义规格。
